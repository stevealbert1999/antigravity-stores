# AI Financial Leak Detector

## One-line promise

Upload a finance CSV and instantly find wasted spend, duplicate charges, suspicious vendors, subscription leakage and cashflow risks.

## Why this product

This is designed as a self-serve financial value product, not an enterprise demo-call product.

The user should get value in under 60 seconds.

## Target users

- founders
- small business owners
- agencies
- ecommerce operators
- finance leads in SMBs
- fractional CFOs

## Core user flow

1. User lands on page.
2. User uploads CSV.
3. System classifies transactions.
4. System detects leaks.
5. User receives instant report.
6. User sees estimated recoverable money.
7. User can export report or upgrade to monitoring.

## MVP input

CSV with columns:

```txt
date,vendor,description,amount,currency,category
```

## MVP leak categories

- duplicate payments
- recurring subscriptions
- high spend vendors
- suspicious spikes
- unknown vendors
- avoidable SaaS spend
- negative cashflow trend

## Viral hook

```txt
We found €X/month in wasted spend from your CSV.
```

## Product rule

Do not start with bank integrations. Start with CSV because it removes friction and avoids compliance complexity.
